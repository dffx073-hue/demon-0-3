Нейропошук по інтернету

Шукає по-справжньому в інтернеті (через відкритий API Wikipedia — без ключа, без сервера) і підказує варіанти запиту на льоту. Результати переранжовує маленька нейромережа, яка вчиться на ваших кліках.

мережа готова
Джерело даних — uk.wikipedia.org/w/api.php, відкрите й безкоштовне, працює прямо з браузера без ключа. Якщо потрібен пошук як у Google/Bing по всьому вебу — це можливо, але тільки з API-ключем (Google Programmable Search, Bing Search API або SerpAPI), бо самі пошукові системи не дозволяють браузеру стукатися до них напряму. Функція fetchResults() нижче — єдине місце, яке потрібно замінити на такий API.
